Open Source Philosophy

Pengertian Filosofi Open Source

Open source adalah filosofi yang mendukung distribusi gratis atas source code sebuah software untuk memungkinkan penggunaan, modifikasi, dan redistribusi yang bebas.

Sejarah Singkat

Gerakan open source dimulai pada akhir 1990-an sebagai respons terhadap pembatasan perangkat lunak proprietary.

Dampak Global

Open source telah mengubah cara kita berkolaborasi dalam pengembangan teknologi.

Nilai-nilai Penting Open Source

Keterbukaan (Transparency)

Source code tersedia untuk dilihat, dipelajari, dan dimodifikasi oleh siapa saja.

Kolaborasi (Collaboration)

Pengembang dari seluruh dunia dapat berkontribusi untuk meningkatkan software.

Berbagi Ilmu (Knowledge Sharing)

Pengetahuan dan solusi teknis dibagikan secara terbuka untuk kemajuan bersama.

Kemerdekaan (Freedom)

Pengguna tidak terkunci pada vendor tertentu dan dapat menyesuaikan software sesuai kebutuhan.

Prioritas dalam Studi/Proyek

Nilai yang paling sering saya terapkan dalam studi atau proyek adalah kolaborasi. Dalam mengerjakan tugas maupun proyek pribadi, saya sering berkolaborasi dengan teman-teman untuk saling membantu memecahkan masalah teknis.

Nilai keterbukaan juga saya terapkan dengan membagikan kode proyek saya di platform seperti GitHub untuk mendapatkan masukan dari developer lain.
